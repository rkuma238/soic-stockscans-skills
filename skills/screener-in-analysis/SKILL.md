# Screener.in Company Analysis

Fetch financial data from Screener.in for NSE/BSE-listed companies and generate a structured analysis report.

## Workflow

1. Run `scripts/fetch_company.py <company> --output /tmp/<company>.json` to fetch raw data.
   - `<company>` can be a name (TCS, RELIANCE) or NSE symbol (HDFCBANK).
   - Requires Python 3 with no external dependencies (stdlib only).
   - If the fetch fails (404), try alternate spellings: `TATA MOTORS` → `TATAMOTORS`, `HDFC BANK` → `HDFCBANK`.

2. Read the JSON output. Key sections:
   - `about` — company description
   - `key_metrics` — market cap, P/E, ROE, ROCE, etc.
   - `pros_cons` — Screener.in's automated checklist
   - `growth_rates` — compounded sales/profit/stock growth
   - `roe_history` — ROE over 3/5/10 years
   - `financials` — quarterly, annual P&L, balance sheet, cash flow, ratios, shareholding

3. Read `references/analysis_guide.md` for evaluation criteria.

4. Generate a structured analysis covering:
   - Company Snapshot
   - Valuation
   - Profitability
   - Growth
   - Financial Health
   - Shareholding Pattern
   - Pros & Cons
   - Verdict

## Notes

- Screener.in data is delayed (~15 min for prices, latest quarter for financials).
- Some data (insights, employee metrics) requires login and is not available via the script.
- Always state that pros/cons are machine-generated by Screener.in and recommend independent analysis.
